Introduction & History

  • Computer networking: interconnected computing devices that exchange data and share resources with each other.
  • First network: ARPANET (Advanced Research Projects Agency Network) — USA, Department of Defense, 1969.
  • TCP/IP was developed for ARPANET by Vint Cerf & Bob Kahn (called "Fathers of the Internet").
  • Before TCP/IP, ARPANET used NCP (Network Control Protocol).
  • First e-mail was sent over ARPANET in 1971 by Ray Tomlinson (he also introduced the @ sign in addresses).
  • 1 January 1983 — ARPANET switched to TCP/IP: the "official birthday of the Internet".
  • First public internet service in India: VSNL (Videsh Sanchar Nigam Limited) on 15 August 1995.
  • WWW invented by Tim Berners-Lee (1989, CERN).

Evolution of Networking

  • ARPANET (1969) — first network, connected 4 university/research computers (UCLA, Stanford, UCSB, Utah).
  • NSFNET (1986) — National Science Foundation Network; connected universities and research centres at high speed; replaced ARPANET as the backbone (ARPANET shut down in 1990).
  • Internet — global network of networks formed by interconnecting ARPANET, NSFNET and private networks; opened to commercial use in the early 1990s.

Networking Models: OSI & TCP/IP

A networking model is a set of guidelines and standards that define how data is transmitted and received over a network.

  • TCP/IP model (1970s–1982) — adopted as the standard protocol suite of ARPANET in 1983. Practical model actually used on the Internet.
  • OSI model (Open Systems Interconnection) — published by ISO (International Organization for Standardization) in 1984. 7 layers. It is a reference/conceptual model, not practically implemented as such. Purpose: describe how data travels in a network.

Trick (top→down): All People Seem To Need Data Processing. Bottom→up: Please Do Not Throw Sausage Pizza Away. Layers 1–3 = hardware/"media" layers; 5–7 = software/"host" layers; Transport = "heart of OSI". PDU = Protocol Data Unit.

Layer details

  • Physical layer: physical connection, topology, transmission mode (simplex/half/full duplex), bit synchronization, bit-rate control.
  • Data Link layer: MAC (Ethernet) addressing, error-free transfer of frames, flow control, error control. Node-to-node delivery. Two sub-layers: LLC (Logical Link Control — error/flow control) and MAC (Media Access Control — 48-bit physical address on NIC).
  • Network layer: routing & forwarding of packets, internetworking, logical (IP) addressing, source-to-destination (host-to-host) delivery.
  • Transport layer: end-to-end / process-to-process delivery using port numbers, acknowledgement, segmentation. TCP = connection-oriented, UDP = connectionless. TLS/SSL also operate around here.
  • Session layer: session establishment & management, synchronization (checkpoints), dialog & token management.
  • Presentation layer: also called translation/syntax layer — translation, encryption, compression.
  • Application layer: also called desktop layer; closest to the end user. Network virtual terminal, file transfer (FTAM), mail services, directory services.
A firewall can work at layers 3, 4 and 7 of OSI.

  • Loopback address: 127.0.0.1 (range 127.0.0.0 – 127.255.255.255). Broadcast: 255.255.255.255.
  • Private IP ranges (reserved by IANA): 10.0.0.0–10.255.255.255, 172.16.0.0–172.31.255.255, 192.168.0.0–192.168.255.255. (100.64.0.0/10 is used for carrier-grade NAT.)
  • Private IP is assigned by the router to devices; public IP is assigned by the ISP to the router.
  • IP addresses are managed globally by IANA (Internet Assigned Numbers Authority); in Asia-Pacific (incl. India) by APNIC.
  • IPv6 developed by IETF (Internet Engineering Task Force). Internet was funded by DARPA (Defense Advanced Research Projects Agency).
  • MAC address: first 24 bits = OUI (Organizationally Unique Identifier — manufacturer), last 24 bits = NIC-specific. MAC/Ethernet concept developed at Xerox PARC.
  • ARP finds MAC address from IP address; RARP finds IP from MAC.
  • How to change your IP: restart modem/router, use VPN, use a proxy server, contact your ISP.
  • Logical address = IP address (virtual); Physical address = MAC address.

Subnetting

A subnet is a network inside a network. Subnetting divides a large network into smaller ones — makes networks efficient and improves security.

  • Number of hosts = 2h − 2 (h = host bits; network ID and broadcast ID excluded).
  • Number of subnets = 2n (n = borrowed bits).
Q. How many hosts with mask 255.255.255.128? → last octet 10000000 → 7 host bits → 27 − 2 = 126.
Q. Mask 255.255.255.252? → 2 host bits → 22 − 2 = 2 hosts.
Q. Host part of 192.168.10.51 with default mask (class C)? → network 192.168.10, host 51.

Ports & Protocols

A port identifies the sender/receiver process of a message. Ports are used at the transport layer (layer 4). Each host can have 65,535 ports per IP address.

  • DNS (Domain Name System): converts domain name → IP address.
  • DHCP (Dynamic Host Configuration Protocol): assigns IP addresses to hosts automatically.
  • ICMP: used by network devices to send error messages and operational info (e.g. ping).
  • Gopher: early protocol for distributing, searching and retrieving documents over the Internet.
  • HTTPS uses SSL/TLS for encryption.

E-mail protocols

  • SMTP — send mail. POP3 — download mail from server to local device (used by MS Outlook, Thunderbird, Apple Mail). IMAP — read mail on server without downloading, syncs across devices (webmail like Gmail).
  • MIME (Multipurpose Internet Mail Extensions) — sending attachments.

Transmission Modes

  • Simplex — one direction only: keyboard→CPU, monitor output, radio/TV broadcasting, fire-alarm system, loudspeaker.
  • Half duplex — both directions, one at a time: walkie-talkie (push-to-talk), browsing (request/response).
  • Full duplex — both directions simultaneously: mobile phone, video conferencing, live chat.

Data Communication

Components

  • Sender, Receiver, Message, Communication medium (wired/wireless), Protocol (rules).

Terms

  • Channel — path through which data travels.
  • Bandwidth — range of frequencies a channel can carry = highest − lowest frequency; measured in Hz (KHz, MHz, GHz). Higher bandwidth → more data.
  • Data transfer rate — bits transferred per second: bps, Kbps (103), Mbps (106), Gbps (109), Tbps (1012). (Mbps = megabits; MBps = megabytes; 1 byte = 8 bits.)
  • Baud rate — signal changes per second.
  • Latency — delay; throughput — actual data delivered per second.

Switching techniques

Circuit switchingPacket switching
Dedicated path set up before communication (call setup)Message broken into packets; each packet may take a different route

Telephone networkInternet

Message switching — whole message sent hop by hop (store-and-forward), no dedicated path.

More protocols

  • PPP (Point-to-Point Protocol) — direct link between two nodes (dial-up, broadband to ISP); data-link layer; supports authentication.
  • VoIP (Voice over Internet Protocol) — voice calls over the Internet (WhatsApp call, Skype, Zoom).
  • Telnet — remote login (insecure, port 23); SSH is the secure replacement.

Network Topology

Topology = physical or logical layout of a network.

TopologyDescription
BusSingle backbone cable with terminators at ends; multipoint; fault isolation difficult; performance degrades with more computers/heavy traffic. Uses CSMA/CD.
StarAll nodes connect to a central hub/switch; common in LAN; hub failure stops network.
RingEach node connects to two neighbours; token passing (Token Ring, FDDI); uni/bi-directional.
TreeHierarchy of multiple star (hub) networks.
MeshPoint-to-point links between every node; very reliable, costly wiring. Links in full mesh = n(n−1)/2 (n = 6 → 15).
HybridCombination of 2 or more topologies.
  • CSMA/CD — Carrier Sense Multiple Access with Collision Detection (Ethernet). CSMA/CA — Collision Avoidance (Wi-Fi).
  • FDDI — Fiber Distributed Data Interface (ring).

Networking Devices

  • Hub — dumb device, broadcasts to all ports (layer 1).
  • Repeater — regenerates signal; "active hub" (layer 1).
  • Bridge — connects two segments of the same network (layer 2).
  • Switch — sends frames to the right port using MAC table (layer 2). A layer-2 switch is also called a multiport bridge.
  • Router — interconnecting device at layer 3; forwards packets between networks using a routing table (purpose: find most efficient path). Used in LAN & WAN. Features: firewall, VPN, traffic monitoring. Wi-Fi frequency 2.4 GHz & 5 GHz. Makers: Cisco, D-Link, TP-Link.
  • Gateway — connects two different networks / protocols (works up to layer 7).
  • Modem — MOdulator (digital → analog) + DEModulator (analog → digital).
  • Firewall — hardware + software security barrier.
  • Dial-up — uses telephone lines + modem (slowest). DSL (Digital Subscriber Line) — faster broadband via router.

Transmission Media (Cables)

Guided (wired)

  • Twisted pair — STP (Shielded, used in factories), UTP (Unshielded, LAN). Connector RJ-45 (8 pins, Ethernet); RJ-11 (6 positions/4 or 2 wires, telephone).
  • Coaxial — TV cable; connector BNC (Bayonet Neill–Concelman).
  • Optical fibre — fastest; undersea cables, broadband. Connectors: SC (Subscriber Connector), ST (Straight Tip), LC (Lucent Connector), FC (Ferrule Connector). Works on total internal reflection.

Unguided (wireless)

  • Radio waves — wireless mouse, FM, AM.
  • Microwaves — remote sensing, radar, mobile, satellite.
  • Infrared — short range: TV remote, thermal imaging, astronomy.

Web Basics

  • Internet = the network infrastructure; WWW = a service on the Internet (pages linked by hyperlinks, accessed by HTTP).
  • Web page — single HTML document. Website — collection of related web pages under one domain. Home page — first page of a website.
  • Static web page — same content for everyone; dynamic — generated at request time.
  • Web browser — software to view web pages (Chrome, Firefox, Edge, Safari). Web server — stores and serves pages (Apache, Nginx).
  • Web hosting — storing a website on a server connected to the Internet so others can access it.
  • Domain name — human-readable address (bpsc.bihar.gov.in); converted to IP by DNS. URL — complete address of a resource.
  • Browser add-ons/plug-ins, cookies (small text files stored by a site in the browser).

Exam Facts

  • Protocol that sends a datagram to an application program: UDP.
  • Dialogue & token management: Session layer.
  • Hardware for WAN: Router.
  • Port address size in TCP/IP: 16 bits. IPv6 length: 128 bits.
  • Device connecting two systems with different protocols: Gateway.
  • Address identifying a process on a host: Port. Address of a node as defined by LAN/WAN: Physical (MAC).
  • Layer that lets users access the network: Application.
  • Short-range waves between PC and peripherals: Infrared.
  • Protocols for real-time video/gaming: UDP; real-time text chat: IRC.
  • Packets to frames: Data link layer. Contention-based MAC protocol in Ethernet: CSMA/CD.
  • Maximum length of an IPv4 datagram: 65,535 bytes (216 − 1).
  • First-octet higher-order bits for class D: 1110.
  • With Telnet/FTP you use the Application layer (highest layer).
