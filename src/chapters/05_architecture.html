Computer Architecture & Memory

Computer Organization & CPU

  • Father of computer architecture: John von Neumann (stored-program concept — program and data stored in the same memory).
  • Parts of a computer: CPU, memory, input devices, output devices.
  • CPU (Central Processing Unit) = processor / microprocessor; "brain of the computer". Understands only machine language (binary).
  • CPU speed measured in Hertz — MHz, GHz. Also MIPS (Million Instructions Per Second), KIPS (Kilo IPS).
  • Parts of CPU: CU (Control Unit — controls input/output, decodes instructions), ALU (Arithmetic Logic Unit — executes arithmetic & logical operations; result stored in accumulator), MU (Memory unit — registers, fastest memory).
  • Machine (instruction) cycle: Fetch → Decode → Execute (→ Store).
  • System bus: address bus (unidirectional), data bus (bidirectional), control bus.

Microprocessor

  • First microprocessor: Intel 4004 (4-bit), 1971.
  • Intel = Integrated Electronics; AMD = Advanced Micro Devices.
  • Types of CPU by cores: single (Intel 4004), dual, quad, hexa (6), octa (8), deca (10).
  • 8085: Intel, 1976, 8-bit data bus, 16-bit address bus (64 KB), 40 pins; 3rd-gen use in home appliances.
  • 8086: 16-bit data, 20-bit address (1 MB memory).

Memory Hierarchy

Fastest → slowest: Registers → Cache → Main memory (RAM) → Secondary storage (HDD/SSD) → Tertiary (tape). Speed and cost per bit decrease, capacity increases going down.

  • Primary / internal / main memory: RAM, ROM (semiconductor memory). Cache & registers are also considered primary.
  • Secondary / external memory: HDD, SSD, CD, DVD, Blu-ray, pen drive, memory card.

RAM

  • Random Access Memory — temporary, volatile, read + write. Founder (DRAM): Robert Heath Dennard (IBM, 1966).
  • SRAM (Static) — made of transistors/flip-flops; fastest; no refresh; used for cache memory; costly.
  • DRAM (Dynamic) — made of capacitors; slower; needs refreshing; used as main memory in PCs/mobiles.
  • DRAM types: SDRAM (Synchronous DRAM), DDR SDRAM (Double Data Rate) — DDR1, DDR2, DDR3, DDR4, DDR5.

ROM

  • Read Only Memory — non-volatile, permanent; stores BIOS / firmware (firmware = hardware + software); helps in booting.
  • PROM — Programmable ROM, written once, no editing (Wen Tsing Chow, 1956).
  • EPROM — Erasable PROM, erased by UV rays (Dov Frohman, 1971).
  • EEPROM — Electrically Erasable PROM, erased by electric signals (George Perlegos).
  • Flash memory — type of EEPROM: pen drive, memory card, SSD (invented by Fujio Masuoka, Toshiba).
  • Booting: loading the OS from secondary storage into RAM. Cold boot (power on) / warm boot (restart). BIOS → POST (Power-On Self-Test) → bootloader.

Cache Memory

  • 2nd fastest memory; volatile; small (KB – MB); located between CPU and RAM; stores frequently used instructions & data.
  • Data found in cache = hit; not found = miss. Performance measured by hit ratio = hits / (hits + misses).
  • Levels: L1 (inside core, fastest), L2, L3 (shared).
  • LRU (Least Recently Used) — common cache replacement policy: discards the least recently used item first when the cache is full.
  • Word transfer: CPU ↔ cache; block transfer: cache ↔ main memory.
  • Cache mapping: Direct, Associative (fully), Set-associative.

Registers

  • Fastest memory; inside CPU; collection of flip-flops. Holds 32/64 bits. CPU word size = register size.
  • Functions: fetch, decode, execute.

Latch vs Register: a latch holds 1 bit and is asynchronous (level-triggered, no clock); a register is a group of flip-flops with a clock (edge-triggered) storing multiple bits.

Virtual, Buffer & Flash Memory

  • Virtual memory — illusion of a larger RAM; uses secondary storage; swap in/swap out; implemented via paging/segmentation (page replacement).
  • Buffer — temporary storage in RAM to hold data before use (e.g. video buffering: first part downloaded then played).
  • Flash — pen drive (USB stick), memory stick, SD card, SSD.

SIMM vs DIMM

  • SIMM — Single In-line Memory Module: 30 / 72 pins; 32-bit data path; 4 MB – 64 MB; 5 V.
  • DIMM — Dual In-line Memory Module: 168 / 184 / 240 / 288 pins; 64-bit; 32 MB – many GB; 3.3 V or lower. SO-DIMM for laptops.

Secondary Storage Devices

  • HDD — magnetic platters, tracks & sectors; first HDD IBM 350 (1956, 5 MB).
  • SSD — flash-based, no moving parts, faster.
  • Optical: CD (~700 MB), DVD (4.7 GB single layer), Blu-ray (25 GB single layer) — read by laser.
  • Magnetic tape — sequential access, used for backup.
  • Disk access time = seek time + rotational latency + transfer time.
