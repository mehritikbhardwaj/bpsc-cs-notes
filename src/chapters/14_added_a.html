Classification of Computers

  • By data handled: Analog (continuous data — thermometer, speedometer), Digital (discrete 0/1), Hybrid (both — ICU machines).
  • By size/power: Supercomputer (fastest; measured in FLOPS; e.g. Frontier/El Capitan) > Mainframe (banks, many users) > Minicomputer > Microcomputer (PC, laptop, tablet, smartphone).
  • By purpose: general purpose and special purpose (embedded).

Input & Output Devices

  • Input: keyboard (QWERTY by Christopher Sholes), mouse (Douglas Engelbart, 1960s), scanner, joystick, light pen, touchscreen, microphone, webcam, barcode reader, MICR (Magnetic Ink Character Recognition — bank cheques), OCR, OMR (Optical Mark Reader — answer sheets), biometric sensor, trackball, graphics tablet.
  • Output: monitor (CRT, LCD, LED, OLED), printer, plotter (large drawings), speaker, projector, headphones.
  • Printers: impact (dot matrix, daisy wheel, line printer) and non-impact (inkjet, laser, thermal). Speed: CPS (characters/sec), LPM (lines/min), PPM (pages/min).
  • Both input & output: touchscreen, modem, network card, headset.
  • Monitor resolution in pixels; refresh rate in Hz. Keyboard function keys F1–F12.

Software

  • System software: operating system, device drivers, utilities (antivirus, disk cleanup), language translators (compiler, interpreter, assembler), firmware.
  • Application software: word processors (MS Word), spreadsheets (Excel), presentation (PowerPoint), DBMS, browsers, media players, games.
  • Licensing: proprietary (closed source), freeware (free, closed), shareware (trial), open source (source available — Linux, LibreOffice, Firefox), FOSS (Free and Open Source Software).
  • Hardware = physical parts; software = programs; firmware = software stored in ROM; liveware/humanware = users.

Ports & Buses

  • USB (Universal Serial Bus, 1996) — Type A, B, C; USB 2.0 (480 Mbps), 3.0 (5 Gbps), USB4 (40–80 Gbps).
  • HDMI (High-Definition Multimedia Interface), VGA (Video Graphics Array), DVI, DisplayPort, Thunderbolt, Ethernet (RJ-45), PS/2 (old mouse/keyboard), serial (COM) and parallel (LPT) ports.
  • Motherboard: CPU socket, RAM slots, chipset, PCIe slots, SATA ports, BIOS/UEFI chip, CMOS battery.

Python Programming & Pandas

Python Basics

  • High-level, interpreted, dynamically typed, object-oriented language by Guido van Rossum, released 1991; named after "Monty Python's Flying Circus". Files: .py. Current major version: Python 3.
  • Uses indentation (not braces) for blocks. Case-sensitive. Comments: #; docstrings in triple quotes.
  • Modes: interactive (shell, >>>) and script mode. IDLE = Integrated Development and Learning Environment.
  • 35 keywords in Python 3 (e.g. True, False, None, and, or, not, if, elif, else, for, while, break, continue, def, return, lambda, class, try, except, finally, import, from, as, with, pass, global, nonlocal, in, is, del, assert, raise, yield, async, await).

Operators

  • Arithmetic: + - * / // % ** — / true division (7/2 = 3.5), // floor division (7//2 = 3), ** power (2**3 = 8).
  • Relational: == != > < >= <=; logical: and or not; membership: in, not in; identity: is, is not.
  • Precedence: ** > unary - > * / // % > + - > relational > not > and > or. ** is right-associative: 2**3**2 = 512.

Strings, Lists, Tuples, Dictionaries

  • Indexing from 0; negative indexing from −1. Slicing s[start:stop:step]; s[::-1] reverses.
  • String methods: upper(), lower(), title(), strip(), split(), join(), replace(), find(), count(), isdigit(), isalpha(), len().
  • List methods: append(), extend(), insert(), remove(), pop(), sort(), reverse(), index(), count().
  • Dict methods: keys(), values(), items(), get(), update(), pop().
  • List comprehension: [x*x for x in range(5) if x % 2 == 0] → [0, 4, 16].

Data Handling with Pandas

  • Pandas (by Wes McKinney, 2008) — library for data analysis; built on NumPy. Import: import pandas as pd.
  • Series — 1-D labelled array. DataFrame — 2-D labelled table (rows & columns).
import pandas as pd
s = pd.Series([10, 20, 30], index=["a", "b", "c"])
df = pd.DataFrame({"Name": ["Ravi", "Sita"], "Marks": [82, 91]})
df.head(); df.tail(); df.shape; df.columns; df.describe()
df["Marks"].mean()
df[df["Marks"] > 85]                 # filtering
df.loc[0, "Name"]; df.iloc[0, 1]     # label vs position
df.sort_values("Marks", ascending=False)
df.groupby("Name")["Marks"].sum()
df.to_csv("out.csv", index=False); pd.read_csv("out.csv")
  • Handling missing data: isnull(), dropna(), fillna().
  • Matplotlib (pyplot) for plotting: plt.plot(), bar(), hist(), pie(), scatter(), show(), savefig().
  • NumPy — n-dimensional arrays (ndarray), fast vectorised math.

Web Technology

WWW & Internet Basics

  • WWW — invented by Tim Berners-Lee at CERN (1989); first website 1991. Collection of web pages linked by hyperlinks, accessed over the Internet using HTTP.
  • URL structure: https://www.example.com:443/path/page.html?id=5#top → protocol, domain, port, path, query, fragment.
  • Web browser: first browser "WorldWideWeb" (Nexus); first popular graphical browser Mosaic (1993). Today: Chrome, Firefox, Edge, Safari, Opera.
  • Web server: Apache, Nginx, Microsoft IIS. Search engine: Google (1998), Bing, DuckDuckGo. First search engine: Archie (1990).
  • Static website (fixed HTML) vs dynamic website (content generated by server — PHP, Node.js, Python).
  • Front end: HTML, CSS, JavaScript. Back end: PHP, Node.js, Python (Django/Flask), Java. Database: MySQL, MongoDB.
  • Domains: TLDs .com, .org, .edu, .gov, .in (India). Domain names managed by ICANN; .in registry by NIXI.
  • HTTP status codes: 200 OK, 301 moved, 403 forbidden, 404 not found, 500 server error.
  • Cookies — small text files stored by websites in the browser. Cache — stored copies for faster loading.

HTML

  • HyperText Markup Language — structure of web pages; by Tim Berners-Lee (1991). Current version: HTML5 (W3C/WHATWG). Not a programming language. Tags are case-insensitive.
  • Container tags (with closing tag: <p></p>) and empty tags (<br>, <hr>, <img>).
<!DOCTYPE html>
<html>
  <head><title>My Page</title></head>
  <body>
    <h1>Heading</h1>  <!-- h1 to h6 -->
    <p>Paragraph with <b>bold</b> and <i>italic</i></p>
    <a href="https://bpsc.bihar.gov.in">Link</a>
    <img src="pic.jpg" alt="photo" width="200">
    <ul><li>Unordered</li></ul>  <ol><li>Ordered</li></ol>
    <table border="1"><tr><th>Head</th></tr><tr><td>Cell</td></tr></table>
    <form action="/submit" method="post">
      <input type="text" name="user"> <input type="submit">
    </form>
  </body>
</html>
  • Table attributes: rowspan, colspan, cellpadding, cellspacing. List types: ordered (type="1|A|a|I|i"), unordered, description (<dl><dt><dd>).
  • HTML5 semantic tags: <header>, <nav>, <section>, <article>, <aside>, <footer>; media: <audio>, <video>, <canvas>.
  • Form methods: GET (data in URL, limited, not secure) and POST (data in body).
  • XML — eXtensible Markup Language — stores/transports data; user-defined tags; case-sensitive. DHTML = HTML + CSS + JavaScript.

CSS

  • Cascading Style Sheets — presentation/styling; by Håkon Wium Lie (1994). Types: inline (style attribute), internal (<style> in head), external (.css file via <link>). Priority: inline > internal/external (later wins) > browser default.
  • Selectors: element (p), class (.box), id (#main), universal (*), group (h1, h2), descendant (div p).
  • Box model: content → padding → border → margin.
  • Layouts: Flexbox, Grid; responsive design with media queries.
.box { color: #333; background: lightblue; padding: 10px; margin: 5px; border: 1px solid black; }

JavaScript

  • Client-side scripting language by Brendan Eich (Netscape, 1995; created in 10 days; earlier names Mocha, LiveScript). Standard: ECMAScript. Not related to Java.
  • Variables: var, let, const. Output: console.log(), alert(), document.write().
  • DOM (Document Object Model) — tree of page elements: document.getElementById("x").innerHTML = "Hi";
  • Events: onclick, onload, onchange, onsubmit, onmouseover.
  • Node.js — runs JavaScript on servers (Ryan Dahl, 2009). JSON — JavaScript Object Notation (data format).
