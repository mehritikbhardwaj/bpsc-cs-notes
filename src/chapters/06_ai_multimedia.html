Artificial Intelligence & Machine Learning

Artificial Intelligence

  • AI is the science of making machines that can think like humans — learn from experience, adapt to new inputs and perform human-like tasks.
  • Examples: chess-playing computers, self-driving cars, chatbots — heavily based on deep learning and NLP.
  • Father of AI: John McCarthy — coined the term "Artificial Intelligence" in 1956 (Dartmouth Conference). He also created LISP (1958).
  • Alan Turing proposed the Turing Test (1950) to check machine intelligence.
  • First AI program demonstration: Carnegie Mellon University (Logic Theorist, Newell & Simon, 1956).
  • AI systems = machine (hardware) + software. Machines become intelligent once they are trained.
  • Relationship: AI ⊃ Machine Learning ⊃ Deep Learning. Most advanced form of AI today: deep learning.
  • AAAI = Association for the Advancement of Artificial Intelligence (earlier "American Association for AI").

Types of AI (by functionality)

  1. Reactive machines (e.g. IBM Deep Blue)
  2. Limited memory (self-driving cars)
  3. Theory of mind
  4. Self-aware AI

Types of AI (by capability)

Narrow/Weak AI (ANI) — today's AI; General AI (AGI) — human-level; Super AI (ASI) — beyond humans (hypothetical).

Branches of AI

Machine Learning, Deep Learning, Natural Language Processing (NLP), Robotics, Expert Systems, Fuzzy Logic, Computer Vision.

AI evolution: Birth of AI → Neural networks → Machine learning → Deep learning → Generative AI.

AI languages

Python (most popular), LISP (first AI language — "List Processing"), Prolog ("Programming in Logic"), Java, JavaScript, C++, Julia, Haskell, Scala, R.

Machine Learning

  • Branch of AI focused on using data and algorithms to let machines learn without explicit programming.
  • Term "Machine Learning" coined by Arthur Samuel (IBM) in 1959.
  • Geoffrey Hinton — "Godfather of Deep Learning" (Nobel Prize in Physics 2024 with John Hopfield).

Types of ML

  1. Supervised — trained on labelled data; maps input X to output Y. E.g. risk assessment, fraud detection, spam filtering. Algorithms: linear/logistic regression, decision tree, SVM, KNN.
  2. Unsupervised — no labels; discovers hidden patterns/groups. E.g. clustering (K-means), anomaly detection.
  3. Reinforcement — feedback-based (reward/penalty), trial and error; autonomous self-teaching system. E.g. game-playing (AlphaGo), robotics.

7 steps of ML

Gathering data → Preparing data → Choosing a model → Training → Evaluation → Hyperparameter tuning → Prediction.

Deep Learning

  • Subset of ML using artificial neural networks with many layers; solves complex problems and creates new features itself.
  • Examples: self-driving cars, chatbots, facial recognition, voice assistants.
  • Three layers: input layer, hidden layer(s), output layer.
  • Types: CNN (images), RNN/LSTM (sequences), Transformers (language — basis of GPT), GAN (generating images).

Multimedia

What is Multimedia

  • Integration of text, drawings/graphics, still images, moving images (video), audio and animation.
  • Term "multimedia" coined by singer & artist Bob Goldstein in July 1966.
  • Hardware for multimedia: input devices, CPU, output devices, storage devices, memory (RAM), graphics card, sound card.

Protocols for multimedia

  • RTP (Real-time Transport Protocol) — video conferencing, live streaming (Zoom, Skype).
  • RTSP (Real Time Streaming Protocol) — controls media sessions: play, pause, fast forward (Netflix-type).

Warping, Morphing & Image Types

  • Warping — digitally manipulating/distorting one static image to produce another.
  • Morphing — animation that changes one image slowly into another.

Multimedia Authoring

  • Creating a multimedia project using authoring software (sets tools together).
  • Software: Macromedia/Adobe Flash, Macromedia Director, Authorware, Quest.

  • Stages of a multimedia project: Planning → Designing → Developing → Testing → Delivering.

Compression

  • Reducing file size by encoding.
  • Lossless — no quality lost; original can be restored: ZIP, PNG, BMP, WAV, FLAC, GIF.
  • Lossy — permanently removes some data: JPEG images, MP3 music, streaming video, MPEG-4.

Animation & Colour Basics

  • Frame rate: films 24 fps, TV 25/30 fps. Animation types: 2D, 3D, stop-motion, cel animation; tweening = generating frames between key frames.
  • Colour models: RGB (additive — screens), CMYK (subtractive — printing). Resolution measured in PPI (screen) / DPI (print).
