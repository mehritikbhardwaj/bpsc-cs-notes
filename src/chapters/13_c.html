C Programming (Complete)

Introduction to C

  • Programming = a medium to communicate with computers (like Hindi/English between people) to deliver instructions.
  • C is one of the oldest and finest programming languages, developed by Dennis Ritchie at AT&T's Bell Labs, USA, in 1972. Middle-level, procedural, structured.
  • Uses: major parts of Windows, Linux and other OS kernels; device drivers (tablets, printers); embedded systems (microwave, cameras) where speed and limited memory matter; games and other latency-sensitive software.

Ch 1: Variables, Constants & Keywords

  • Variable — a container that stores a value; value can change. E.g. a = 3; b = 4.7; c = 'A';
  • Rules for naming: first character must be a letter or underscore; no commas or blanks; no special symbol other than _; names are case-sensitive; can't be a keyword. Use meaningful names.
  • Constant — entity whose value doesn't change. Types: integer (−1, 6, 7, 9), real (−322.1, 2.5, 7.0), character ('a', '$', '@' — enclosed in single quotes).
  • Keywords — 32 reserved words in C (C89): auto, break, case, char, const, continue, default, do, double, else, enum, extern, float, for, goto, if, int, long, register, return, short, signed, sizeof, static, struct, switch, typedef, union, unsigned, void, volatile, while.
#include <stdio.h>
int main() {
    printf("Hello, I am learning C");
    return 0;
}   // file: first.c

Basic structure & rules

  • Every program's execution starts from main(); every statement ends with a semicolon; instructions are case-sensitive and executed in the order written.
  • Comments: single-line // ..., multi-line /* ... */; not executed.

Compilation & execution

first.c → C compiler (gcc) → first.exe / a.out. The compiler converts the C program into machine language after checking it. Stages: preprocessing → compilation → assembly → linking.

Library functions, format specifiers & input

  • printf("This is %d", i); — %d int, %f float, %c char, %s string, %lf double, %u address/unsigned, %p pointer.
  • scanf("%d", &i); — & is the "address of" operator: value is stored at the address of i.
  • Types of variables: int a = 3; float b = 7.7; char c = 'B';
Practice set 1: area of a rectangle (hard-coded & user input); area of a circle and volume of a cylinder; Celsius → Fahrenheit; simple interest.

Ch 2: Instructions & Operators

Types of instructions: type declaration, arithmetic, control instructions.

  • int a; float b;   int i = 10; int j = i, a = 2;   float b = a + 3; float a = 1.1; → error (a used before definition).
  • int a, b, c, d; a = b = c = d = 30; → all 30.
  • Arithmetic: + − * / %. % (modular division) returns the remainder; can't be applied on float; sign of result = sign of numerator (−5 % 2 = −1, 5 % −2 = 1).
  • No operator is assumed: int i = ab is invalid, use a*b.
  • No exponent operator in C; use pow(x, y) from <math.h>.

Type conversion

OperationResult

int a = 3.5; → a = 3 (float demoted). float a = 8; → 8.0 (promoted). int k = 3.0/9; → 0.333 can't be stored in int → k = 0.

Operator precedence & associativity

In C, BODMAS doesn't apply directly; precedence and associativity decide. Priority: 1st * / %, 2nd + −, 3rd =. Operators of equal priority: associativity — * / left to right. x*y/z = (x*y)/z; x/y*z = (x/y)*z. 3x − 8y must be written 3*x - 8*y.

Ch 3: Conditional Instructions

Decision-making: if-else and switch.

int a = 23;
if (a > 18) {
    printf("You can drive\n");
} else {
    printf("You cannot drive\n");
}
  • else block is optional. Any non-zero value is true; 0 is false.
  • Relational operators: == >= > < <= !=. = is assignment, == is equality check.
  • Logical operators: && (AND — true if both true), || (OR — true if at least one true), ! (NOT — inverts). !(3==3) → false.
  • else if ladder reduces indentation; last else runs only if all conditions fail.

Operator precedence (high → low)

! → * / % → + − → < > <= >= → == != → && → || → =

Conditional (ternary) operator

condition ? expression_if_true : expression_if_false;

switch

switch (marks / 10) {
    case 10: case 9: printf("A"); break;
    case 8: printf("B"); break;
    case 7: printf("C"); break;
    default: printf("F");
}
  • Cases can be in any order; char values allowed (evaluated as integers); switch can be nested (rare). Without break, execution "falls through" to later cases.

Ch 4: Loop Control Instructions

Loops repeat a set of instructions. Types: while, do-while, for.

int i = 0;
while (i < 10) {             // entry controlled
    printf("%d\n", i); i++;
}
do {                         // exit controlled: runs at least once
    printf("%d\n", i); i--;
} while (i > 0);
for (int j = 0; j < 3; j++) // initialize; test; increment
    printf("%d\n", j);
  • If the condition never becomes false → infinite loop.
  • i++ / i-- (post: use then change), ++i / --i (pre: change then use). +++ does not exist. Compound assignment: += -= *= /= %=.
  • Decrementing loop: for (i = 5; i; i--) runs until i becomes 0.
  • break — exits the loop immediately. continue — skips the rest of the current iteration.

Ch 5: Functions & Recursion

#include <stdio.h>
void display();              // prototype (declaration)
int main() {
    display();               // function call
    return 0;
}
void display() {             // definition
    printf("Hi I am display");
}
  • A function is a block of code that performs a particular task; reusable any number of times.
  • Prototype tells the compiler about the function in advance; call transfers control to the function body; definition contains the instructions. While the function runs, main is suspended.
  • Types: library functions (printf, scanf, sqrt) and user-defined.
  • Why functions: avoid rewriting code, keep track of logic, test independently.
  • Parameters — placeholders in the definition; arguments — actual values passed. A function returns only one value at a time.
  • Changing a parameter inside the function doesn't change the caller's variable (a copy is passed — call by value).

Recursion

int factorial(int x) {
    if (x == 0 || x == 1) return 1;   // base condition
    return x * factorial(x - 1);
}
// factorial(5) = 5 * 4 * 3 * 2 * 1 = 120

A function without a base condition recurses forever → memory (stack overflow) error.

Ch 6: Pointers

  • A pointer is a variable that stores the address of another variable.
  • & (address-of) gives the address; * (value-at / dereference) gives the value at an address. Format specifier for address: %u or %p.
int i = 72;
int *j = &i;     // j stores address of i
printf("%d", *j); // 72
int **k = &j;    // pointer to pointer

Call by value vs call by reference

void swap(int *x, int *y) {   // call by reference
    int temp = *x; *x = *y; *y = temp;
}
int a = 3, b = 4;
swap(&a, &b);                // now a = 4, b = 3

Call by value sends copies (originals unchanged); call by reference sends addresses (function can modify originals).

Ch 7: Arrays

  • Collection of similar elements; one variable holds multiple values. Index starts at 0.
  • int marks[90]; char name[20]; float percentage[90];   int cgpa[3] = {9, 8, 8};
  • Stored in contiguous memory: int arr[3] reserves 3 × 4 = 12 bytes.
  • Pointer arithmetic: incrementing a pointer moves it to the next element of its type (int* +4 bytes, char* +1, float* +4). Allowed: add/subtract an integer, subtract two pointers, compare pointers.
  • int *ptr = &arr[0]; then *(ptr + 2) = arr[2]; *(s + 3) refers to the 4th element.
  • Passing to functions: void printArray(int *i, int n) or void printArray(int i[], int n).
  • 2-D: int arr[3][2] = {{1,4},{7,9},{11,22}}; stored row-wise in contiguous memory.

Ch 8: Strings

  • A string is a 1-D character array terminated by the null character '\0'.
  • char s[] = {'H','A','R','R','Y','\0'}; or char s[] = "HARRY"; (null added automatically).
  • Print: printf("%s", s);; input: scanf("%s", s); (no &; stops at space). gets()/puts() read/print multi-word strings (fgets is the safe modern choice).
  • char *ptr = "Harry"; — pointer string can be re-pointed; array string can't be reassigned after declaration.

Ch 9: Structures

struct employee {
    int code;
    float salary;
    char name[10];
};                        // semicolon is important
struct employee e1;
e1.code = 100;
strcpy(e1.name, "Harry");
struct employee *ptr = &e1;
printf("%d", ptr->code);  // arrow operator
typedef struct complex { float real, img; } Complex;
  • Arrays hold similar data; structures hold dissimilar data. Keep data organised.
  • Array of structures: struct employee facebook[100];
  • Stored in contiguous memory. (*ptr).code ≡ ptr->code.
  • typedef creates an alias for a data type.
  • Union — like a structure but all members share the same memory; size = largest member.

Ch 10: File I/O

  • RAM is volatile, so files are used to persist data. A FILE pointer is needed to communicate with a file.
FILE *ptr;
ptr = fopen("Harry.txt", "r");
int num;
fscanf(ptr, "%d", &num);
fclose(ptr);
ptr = fopen("Harry.txt", "w");
fprintf(ptr, "%d", 432);
fclose(ptr);
char c = fgetc(ptr);       // read a character
fputc('c', ptr);          // write a character
while ((c = fgetc(ptr)) != EOF) { /* ... */ }
ModeMeaning

"w" / "wb"Write; overwrites if exists, creates otherwise
"a"Append; creates if it doesn't exist
"r+", "w+", "a+"Read + write variants

File types: text (.txt, .c) and binary (.jpg, .dat). EOF = end of file. Project 2: Snake–Water–Gun game.

Ch 11: Dynamic Memory Allocation

Allocating memory at run time using functions in <stdlib.h>.

FunctionUse
malloc(size)Allocates a block of bytes; returns void*; memory has garbage values. ptr = (int*) malloc(30 * sizeof(int));
calloc(n, size)Continuous allocation; initialises each block to 0. ptr = (float*) calloc(30, sizeof(float));
realloc(ptr, newsize)Resizes previously allocated memory
free(ptr)Releases memory (malloc/calloc memory is not freed automatically)

If memory can't be allocated, a NULL pointer is returned.

Extra C Facts for Exams

  • Size (typical 64-bit): char 1, short 2, int 4, float 4, double 8, long 8 bytes, pointer 8 bytes.
  • sizeof is an operator, not a function. Header for math: <math.h>; for strings: <string.h>; for DMA: <stdlib.h>.
  • Preprocessor directives start with #: #include, #define PI 3.14 (macro), #ifdef.
  • Storage classes in C: auto, register, static, extern.
  • enum creates named integer constants. const makes a variable read-only.
  • Dangling pointer (points to freed memory), NULL pointer (points to nothing), void pointer (generic), wild pointer (uninitialised).
  • Command-line arguments: int main(int argc, char *argv[]).
